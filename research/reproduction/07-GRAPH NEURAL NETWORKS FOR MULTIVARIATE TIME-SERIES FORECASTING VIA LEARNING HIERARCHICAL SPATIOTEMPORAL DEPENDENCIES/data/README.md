# PEMSD8 数据

原始数据不随此仓库上传。请从[作者提供的下载地址](https://drive.google.com/file/d/1p_b8y9Cl2v-hZYPTqVmV9YvTq9YqvYe1/view?usp=share_link)获取，并将 `PEMSD8.npz` 放在：

```text
data/PEMSD8/PEMSD8.npz
```

本次使用文件的 SHA-256 为 `e1d03ce74e9fb79149e6e7c37c680214822c4a285baa2f42278cacabcd25c075`；数组形状为 `(17856, 170, 3)`。从仓库根目录运行训练命令，否则代码中的相对数据路径无法找到文件。
