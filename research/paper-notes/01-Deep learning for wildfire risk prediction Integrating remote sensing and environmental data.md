# 一、读完这篇论文后的笔记

## 1. 这篇论文主要解决了什么问题

这篇文章本身不是提出一个新的森林火灾预测模型，而是一篇比较系统的综述。它主要围绕四件事展开：

1. 森林火灾“风险”到底应该怎么定义；
2. 风险预测应该使用哪些数据和特征；
3. 深度学习在森林火灾风险预测中有哪些主要建模方式；
4. 现有研究还存在哪些问题，未来可以往哪里发展。

对我自己的研究来说，这篇论文最大的价值不是告诉我“哪个模型一定最好”，而是帮我把**数据—特征—模型—解释—风险输出**这一整套研究框架梳理清楚。

论文将深度学习森林火灾预测大体分为三类：**时间序列预测、图像分割/分类、时空预测**。

## 2. 做森林火灾风险预测之前，首先要把“风险”定义清楚

我之前比较容易把“火灾风险”“火灾危险度”“易发性”“起火概率”混在一起，但论文提醒，这几个概念其实不能完全等同。

因此如果我以后写论文，应该明确说明我预测的是：

- 点火风险；
- 燃烧风险；
- 下一日火灾发生概率；
- 还是综合风险等级。

对我来说，如果做**短期风险预测**，比较适合把目标先定义成：

> 在给定当前和过去一段时间的气象、燃料、地形及人类活动条件下，预测未来 1 天或未来几天某网格发生森林火灾的概率。

## 3. 森林火灾预测不能只看气象，真正应该是多源驱动

论文总结的主要影响因素包括：

- 燃料条件；
- 气象和气候条件；
- 地形；
- 水文；
- 社会经济和人类活动；
- 历史火灾信息。

目前大多数研究还是更偏重气象和气候，其次是燃料和地形；社会经济因素和水文因素相对研究不足。

这对我的研究启发比较大。

如果我做“多源数据驱动”，就不能只是把温度、湿度、风速、降水换成深度学习模型，然后说自己是多源数据。

真正的多源应该至少考虑：

```
气象 + 植被/燃料 + 地形 + 人类活动 + 历史火灾
```

如果条件允许，还可以加入土壤湿度、干旱指数、夜间灯光、SAR 等数据。

## 4. 时空模型应该是我重点关注的模型路线

论文把时空建模进一步总结成三种方式：

### 第一种：空间和时间分开建模

例如：

```
CNN->LSTM
```

CNN 提取每一天的空间信息，然后 LSTM 学习时间变化。

这种方法逻辑比较清晰，也比较容易做。

------

### 第二种：空间和时间直接耦合

典型模型：

```
ConvLSTM
```

它不是先把空间数据压成一个向量，而是在 LSTM 内部直接保留空间结构。

这种模型特别适合：

> 过去几天的多源栅格 → 下一天风险图。

论文中总结的一些研究显示，LSTM 和 ConvLSTM 在森林火灾短期预测中通常优于 RF 和普通 CNN。某研究中 ConvLSTM 的 AUC 为 0.926，LSTM 为 0.920。

------

### 第三种：强化空间特征之后再做时空预测

例如：

```
CNN->ConvLSTM
```

甚至：

```
CNN+Attention+ConvLSTM
```

这一类我觉得更适合后续做创新。

因为简单 ConvLSTM 虽然可以建模时空关系，但对于多源数据、不同分辨率数据以及远距离空间关联仍然有限。

## 5.特征处理流程和研究流程

特征处理流程：多源数据->相关性分析->VIF->特征筛选->模型

研究流程：多源数据构建->特征筛选->时空建模->概率校准->模型解释->风险制图
