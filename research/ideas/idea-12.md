1. **原论文创新点1：从“所有变量统一建模”转向“目标变量与外生变量差异化建模”。**TimeXer 针对真实场景中目标序列受到多个外部因素影响的问题，明确预测目标与辅助变量的不同角色，避免完全忽略外生数据或无差别地混合全部变量，使标准 Transformer 能够面向**带外生变量的时间序列预测**建立更合理的信息流。
2. **原论文创新点2：提出内生 Patch 级与外生 Variate 级相结合的双粒度表示。**作者用多个 Patch Token 建模目标序列内部的时间变化，用每个外生变量对应的 Variate Token 表达整段辅助历史，再通过不同类型的注意力分别学习时间依赖与变量间关联，实现**目标序列时间信息的细粒度建模和外生信息的高效融合**。
3. **原论文创新点3：利用内生 Global Token 构建外部驱动信息进入目标序列的桥梁。**通过内生 Patch Token 与全局变量 Token 的 Self-Attention，以及 Global Token 查询外生变量的 Cross-Attention，使外生信息能够先更新目标序列的全局表示，再参与后续时间特征学习；这一结构避免每个内生 Patch 都直接与大量外生变量进行细粒度交互，并且不需要重新定义标准注意力算子。
4. **原论文创新点4：通过跨数据集实验与结构消融验证多源融合方式的有效性。**作者在五个短期电价预测基准和七个长期预测基准上比较多种方法，进一步研究删除或替换不同 Token 表示以及遮蔽外生数据的影响，支持**内生时间信息、全局信息和外生驱动信息联合建模**的设计价值，也揭示外生变量质量下降可能损害预测性能。
5. **面向研究问题1的潜在创新点1：提出环境状态感知的驱动因素级自适应历史窗口选择机制。**与原始 TimeXer 对外生变量采用预设历史长度不同，可以针对温度、降水、植被、土壤湿度等驱动因素建立 7、30、90、180、365 天等候选窗口，并通过 **Environment-aware Driver Router** 根据样本所处季节、干旱状态和区域环境选择每个因素的有效历史范围，使模型从“使用统一回溯窗口”转向**逐样本、逐因素的动态历史选择**。
6. **面向研究问题1的潜在创新点2：设计多历史尺度外生表示与 TimeXer 交叉注意力相结合的融合模块。**在保留外生变量身份的同时，为同一因素构建多个历史窗口的局部或聚合表示，由 Router 先筛选有效尺度，再通过 Global Token 或分层 Cross-Attention 融入火灾风险表示；这样可以避免直接压缩为单个外生 Token 时弱化重要的**历史时滞、累积效应和短期极端事件**信息。需要通过固定窗口、简单多窗口融合和动态路由的对照实验判断其增益是否真实存在。
7. **面向研究问题1的潜在创新点3：提出驱动因素级历史尺度与跨因素作用的联合建模方法。**森林火灾发生条件可能受到持续少雨、燃料湿度降低和短期高温强风等因素共同影响，可以先用独立时间编码学习各驱动因素的历史特征，再借鉴 TimeXer 的 **Variate-wise Cross-Attention** 学习因素间交互，并按不同环境状态动态融合；但需要区分**预测相关性与因果作用**，不能仅凭注意力权重直接声称发现了真实的火灾驱动机制。
8. **面向研究问题2的潜在创新点4：基于多源时序环境表示的困难负样本识别。**通过编码未发生火灾样本的气象、植被和干旱历史，结合与火灾正样本的环境相似性、模型预测难度及地理环境信息，区分**普通负样本与环境相似的困难负样本**；在确认标签较可靠时，对困难负样本使用适度强化采样或损失加权，促使分类模型更准确地区分相似环境下的火灾与非火灾记录。
9. **面向研究问题2的潜在创新点5：将负样本判别难度与标签不确定性分离建模。**高温、干旱却没有发生火灾的区域可能是真实困难负样本，并不必然意味着漏报；因此应独立利用火灾登记完整性、遥感检测条件、空间匹配误差和多源观测一致性估计**标签可信度**，再对可靠困难负样本进行强化学习，对可能误标的样本采用软标签、降低权重或人工复核策略，避免简单提高所有高损失负样本权重带来的噪声放大。
10. **最终可形成“自适应历史尺度—多源驱动融合—难度与可靠性感知训练”的森林火灾预测框架，但这些均属于对 TimeXer 的待验证扩展，而非原论文已完成的研究。**模型可通过 Driver-specific Temporal Router 选择不同因素的历史信息范围，经 TimeXer 风格的跨变量注意力形成环境风险表示，再使用分类预测头和负样本差异化损失进行训练；实验应采用跨年份、跨区域划分，并比较固定历史窗口、TimeXer 基线、动态窗口、困难负样本挖掘和标签可靠性加权的独立贡献，重点评估 **PR-AUC、Recall、误报率和概率校准**。
