## 1. 不同变量采用不同时间窗口

论文统一用了：

```
10天
```

但它自己的解释结果已经表明：

> 不同变量的有效时间尺度不同。

所以我可以进一步设计：

```
Wind：1-3天
Relative\ Humidity：1-3天
Temperature：7-30天
Precipitation：7-30天
Vegetation：更长时间尺度
```

即构建：

> **多时间尺度特征融合模型。**

## 2. 动态变量和静态变量分开编码

论文虽然同时用了动态和静态变量，但我可以进一步明确设计：

```
Dynamic\ Branch（动态变量分支）
```

处理：

- 温度；
- 湿度；
- 风；
- 降水；
- 土壤湿度；
- 植被状态。

同时：

```
Static\ Branch（静态变量分支）
```

处理：

- 海拔；
- 坡度；
- 土地覆盖；
- 道路。

最后再融合。

这应该比简单重复静态变量并和时间序列一起输入更合理。

## 3. 优化负样本构建

这篇论文已经意识到了：

> “没发生火灾”不等于“没有火灾危险”。

但它采用的是从无火灾日期抽取负样本。

我觉得还可以进一步研究：

```
低风险负样本
```

和：

```
高危险但未点火样本
```

之间的区别。

这样模型可能从：

> “识别火灾发生”

进一步转向：

> “真正识别火灾危险条件”。
