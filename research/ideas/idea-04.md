## 1. 多时间尺度输入，而不是所有变量统一使用30天

论文直接使用过去：

```
30天
```

的所有动态变量。

但不同变量的作用尺度其实可能不一样。

比如：

```
Wind（风速）
```

可能主要看：

```
1-3天
```

而：

```
Precipitation（降水）
Soil\ Moisture（土壤湿度）
```

可能应该看：

```
7-30天
```

甚至更长。

所以我可以设计：

```
短期分支+中期分支+长期分支
```

分别提取不同时间尺度的信息。

## 2. 对短期火灾预测增加不确定性输出

传统模型可能输出：

```
Risk=0.8
```

但这个 0.8 未必意味着模型真的很确定。

可以进一步加入：

**Uncertainty Quantification（不确定性量化）**

输出：

```
预测风险+预测不确定性
```

例如：

> 高风险、高置信度；

或者：

> 高风险、但不确定性也很高。

这比单独给一张风险图更适合实际决策。
