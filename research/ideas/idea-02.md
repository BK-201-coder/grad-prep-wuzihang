## 创新点1：构建更完整的多源数据体系

很多已有研究虽然变量不少，但主要还是：

> 气象 + 植被指数 + 地形。

我可以进一步构建：

```
气象 + 燃料 + 地形 + 土地利用 + 人类活动 + 历史火灾
```

的数据体系。

例如：

- ERA5-Land（ERA5陆面再分析数据）：气温、风速、湿度、降水、土壤湿度
- MODIS（中分辨率成像光谱仪）或 Sentinel（哨兵卫星）：植被和水分信息
- DEM（Digital Elevation Model，数字高程模型）：海拔、坡度、坡向
- LULC（Land Use/Land Cover，土地利用/土地覆盖）：土地类型
- 道路、人口、居民点：人类活动
- MODIS/VIIRS（可见光红外成像辐射计）火点：历史火灾

这部分可以作为**数据层面的创新**。

## 创新点2：将共线性分析与模型解释结合

以后可以设计：

```
皮尔逊相关 -> 方差膨胀因子 -> 特征筛选 -> 模型 -> SHAP
```

其中：

**SHAP（SHapley Additive exPlanations，沙普利加性解释）**

用于分析不同变量对预测结果的贡献。

可以进一步比较：

> 共线性处理前后，沙普利加性解释得到的变量重要性排序是否稳定。
